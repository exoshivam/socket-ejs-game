# Socket EJS Multiplayer Game

A real-time multiplayer browser-based card game built using Node.js, Express, EJS, and Socket.IO.

## Features
- Public and private game rooms
- Real-time player communication using Socket.IO
- Waiting lobby before game start
- EJS templating for dynamic UI
- Mobile-friendly interface

## Tech Stack
- Node.js
- Express.js
- EJS
- Socket.IO
- HTML, CSS, JavaScript

## Run Locally
```bash
npm install
node server.js
